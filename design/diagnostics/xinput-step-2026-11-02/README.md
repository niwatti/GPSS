# XInput通常モードのステップ表示修正・ビルド記録

[原因と変更内容](../../12-xinput-observed-step-fix.md)を参照。今回はユーザー指示により試験、ベンチマーク、実機確認を実施していない。公開コマンドによるwin-x64単一EXEの生成だけを行った。VSTest、負荷ツール、アプリ、バンドル検査プログラムは実行していない。

`publish-desktop.log` と `publish-cli.log` は生成ログ。`build-only.json` はEXEのサイズ・SHA256と未実施事項。過去の135件合格を今回の修正へ適用しない。依存lock16件は変更なし。再配布ZIPの整合性とビルド成功は、動作試験の合格とは区別する。
