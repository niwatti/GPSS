```powershell
powershell -ExecutionPolicy Bypass -File scripts/Test-CSharp.ps1 -IncludeDesktop
dotnet run --project src/Gpss.Desktop/Gpss.Desktop.csproj --no-build -- --demo
```

- [ ] 全試験（74件のCore/モック/統合＋8件のWPF STA）を確認する。
- [ ] 左右の点が独立して動き、両軸が動いた後に左8.0bit/右10.0bit、X/Y別値、参考値/件数/最頻割合を表示する。
- [ ] 画面を縮小/拡大し、円・点・四隅・詳細・スクロール・日本語表示を確認する。
- [ ] 推定方式選択、リセット、通常/低遅延と取得設定変更で履歴が混ざらない。
- [ ] 軸割当ダイアログのプレビュー・取消・適用が閉じ、割当が保持/復帰される。設定は起動中のみ有効。
- [ ] 閉じた後にGPSSプロセスが残らない。停止に時間がかかっても画面が応答する。

## HID直接

```powershell
dotnet run --project src/Gpss.Desktop/Gpss.Desktop.csproj --no-build
```

- [ ] HID直接で再検索・機器選択。製品名/候補軸/Usage/Report ID/Link Collection/生値を記録し、必要なら手動割当する。
