# GPSS — Game Pad Stick Stats

GPSSは、ゲームパッドの左右スティックの位置・細かさ・震えを確認するWindows用ツールです。左右のスティックを円形の表示で確認しながら、平均ステップ精度、震えの統計、位置の波形、ステップ精度の分布を計測できます。

## 動作環境と起動方法

- Windows 11（x64）
- Windowsで認識されるゲームパッド（HID直接またはXInputで取得）
- 画面解像度1920×1080を想定。ウィンドウは最大化して起動します。

1. 配布ファイル `GPSS-win-x64.zip` を任意のフォルダーに展開します。
2. ゲームパッドを接続します。
3. 展開先の `desktop/Gpss.Desktop.exe` を起動します。

.NETランタイムを同梱しているため、.NETやPythonの事前インストールは不要です。GUIは単一EXEで動作します。初回起動時には必要なネイティブDLLを一時フォルダー `%TEMP%\.net` に自動展開するため、このフォルダーへ書き込める環境で使用してください。

ゲームパッドなしで画面を試すには、展開先でPowerShellを開き、次を実行します。

```powershell
.\desktop\Gpss.Desktop.exe --demo
```

## 計測を始める

1. 「取得方式」で **HID直接** または **XInput** を選び、「再検索」を押します。
2. 「コントローラー」で計測する機器を選びます。選択すると計測を開始します。
3. 「計測・蓄積期間」を選びます。**10秒／30秒／1分／5分**から選択でき、初期値は30秒です。
4. 左右のスティックをゆっくり動かして、位置と平均ステップ精度を確認します。
5. 震えを確認するときは、スティックを静止させて「計測をリセット」を押し、そのままデータを蓄積します。

すべての統計とグラフは、選択した期間の最新データから更新します。開始直後は、それまでに取得したデータで計算します。期間・機器・取得方式・軸割当・取得設定を変更すると履歴をリセットします。期間の選択は次回起動時にも復元します。

同じゲームパッドがHID直接とXInputの両方に表示される場合も、選択した片方の方式で計測します。取得モードは**低遅延に固定**されており、切り替え操作はありません。

## 表示の見方

| 表示 | 内容 |
| --- | --- |
| 左右の円と点 | 各スティックの現在位置。Xは右が正、Yは下が正です。 |
| 平均ステップ精度 | 隣接する入力値の非ゼロ差分をbit数に換算し、その平均を表示します。左右それぞれのX/Yと、X/Yを合算した値を表示します。 |
| 標準偏差 | 入力値のばらつき。値が小さいほど、選択期間内の位置の変動が小さいことを示します。 |
| 平均 | 選択期間内の入力位置の平均値。中心付近のずれを確認できます。 |
| 平均からの最大偏差 | 平均位置から最も離れた入力値までの距離です。 |
| 位置の波形 | 各軸の位置の変化、平均線、平均±標準偏差の帯。横軸は現在を0秒とした過去の時間です。 |
| ステップ精度のヒストグラム | 左右スティックのX/Y、全4軸の非ゼロ差分をbit数に換算した分布。表示用に小数1桁へ丸め、8〜8.9、9〜9.9など1bit幅で集計します。 |

位置の値は原則として−1〜+1の範囲です。震えの統計には意図的に動かした分も含まれるので、比較するときは期間とスティックの状態をそろえてください。波形の描画を間引いても、統計は取得したデータから計算します。

### 平均ステップ精度について

各差分のbit数は `log2(2.0 / 差分の絶対値)` で求め、丸める前のbit数を平均した後、小数1桁へ四捨五入します。たとえば、差分が `2 / 256` なら8bit相当です。各スティックの合算値は、XとYの有効な差分をすべてまとめた平均です。

スティックを速く動かすと途中の段階を飛ばすため、平均ステップ精度が低くなることがあります。ゆっくり動かして確認してください。変化がない間はステップ精度を計算できません。軸ごとの非ゼロ差分が30個未満の場合は参考値です。「詳細…」で計算対象の件数などを確認できます。

この値は取得できた入力の変化を表すもので、コントローラーの公称bit数を保証する値ではありません。

## 取得方式と設定

| 取得方式 | 特徴 |
| --- | --- |
| HID直接 | ゲームパッドのHIDレポートを直接読み取ります。自動で軸を確定できない機器では、軸割当を設定してください。独自形式のレポートには対応できない場合があります。 |
| XInput | XInput対応コントローラーで利用できます。APIで観測した状態更新を記録します。取得の間に発生したすべての中間状態を読み取れるわけではありません。 |

「軸割当・生値」から、左X・左Y・右X・右Yの割当と反転を設定できます。動かしたスティックと画面の動きが一致するよう、プレビューを確認して適用してください。

「取得設定」ではHIDの完了ポーリングとXInputの休止時間を調整できます。低遅延での取得はCPU使用率が高くなる場合があります。XInputの「状態更新検出/秒」「API呼出し/秒」は、USBのポーリングレートそのものではありません。

設定は `%LOCALAPPDATA%\GPSS\settings.json` に保存します。起動時のコントローラー選択は手動です。

## 困ったとき

- **機器が表示されない：** 接続を確認して「再検索」を押します。HID直接で見つからない場合は、XInputでも確認してください。
- **左右や上下が違う／点が動かない：** 「軸割当・生値」で割当と反転を確認してください。
- **精度が表示されない：** スティックをゆっくり動かし、非ゼロ差分を蓄積してください。
- **震えの値が大きい：** スティックを静止させて「計測をリセット」を押し、再度計測してください。
- **切断後に更新されない：** 再接続し、「再検索」して機器を選び直してください。
- **動作が重い／メモリ使用量が多い：** 計測期間を短くするか、取得設定を調整してください。高頻度入力で5分間を保持すると、多くのメモリを使用します。
- **更新版のEXEを上書きできない：** 起動中のGPSSを終了してから、同じフォルダーへ展開し直してください。

## CSV記録と解析（CLI）

CSV記録を利用する場合は、展開先でPowerShellを開き、`cli/Gpss.Cli.exe` を実行します。

```powershell
# ヘルプを表示
.\cli\Gpss.Cli.exe --help

# XInputで接続機器を確認
.\cli\Gpss.Cli.exe --backend xinput --list

# スロット0の右スティックXを10,000サンプル計測し、全軸をCSVへ記録
.\cli\Gpss.Cli.exe --backend xinput --device 0 --axis rx --samples 10000 --output recording.csv

# 記録済みCSVの右スティックXを解析
.\cli\Gpss.Cli.exe --analyze recording.csv --axis rx
```

指定した準備時間の経過後、Enterキーで計測を開始します。`--no-wait` を付けるとEnter待ちを省略できます。中止するにはCtrl+Cを押します。CLIの平均・標準偏差・最大偏差は、GUIの選択期間とは別に、計測した全区間から計算します。

CSVは既定で8列の互換形式です。元の整数値や取得方式を含めたい場合は `--format v2` を指定してください。列の詳細は[CSV仕様](design/06-csv-format.md)を参照してください。
