# 波形が直近約10秒で切れる問題の修正

更新: 2026-11-02。報告は「−30〜0秒の目盛りは見えるが、波形が約−10〜0秒だけ」。描画範囲の保持方法を修正し、GUI/CLIの単一EXEへ反映する。

## 原因と再現

`LiveAxisWindow.PushProjectionSegment` は8,192点の描画上限に達すると、古い連続区間の表示点を捨てて新着を残していた。統計対象の原データは30秒分あるため、保持時間表示や目盛りは30秒のまま、波形だけ古い側から消える。

XInputの状態番号の飛び、無効値、入力キューの欠落などでcontinuityの区切りが多いと、区間ごとのfirst/min/max/lastによる通常の間引きが効きにくい。毎観測が別区間なら1,000更新/秒で残るのは8.191秒、約800更新/秒なら約10秒となる。この経路は報告と整合する。実機での区切り発生理由・頻度は未計測だが、同条件の合成入力で波形の欠落を再現した。

修正前の再現テスト4件はすべて失敗。45秒の入力を作り、原データが30秒残っているのに、1k更新/秒で8.191秒、8k更新/秒で1.023875秒しか描画に残らないことを確認した。通常の `HistoryProjection.Reduce` にも同じ古い点を捨てる実装があった。[再現と検証資料](diagnostics/history-coverage-2026-11-02/README.md)にログを保存する。

## 修正内容

1. 通常は従来どおり、絶対時刻バケットと連続区間ごとのfirst/min/max/lastを利用する。
2. 8,192点を超える場合は取得済みの有効期間全体を対象に再縮約する。最大1,024時間バケットそれぞれのfirst/min/max/lastを選び、最古点・最新点と各時間帯の極値を残す。
3. 追加の縮約時は最大4,096点、通常時は最大8,192点に収める。古い期間を切り捨てる方針は廃止する。固定出力バッファを再使用し、全原データのコピーを追加しない。バケット全体の代表点も追加時に更新し、失効の影響があるバケットだけ再構築する。区間数が上限を超える場合は区間別走査を省き、この集計を直接使う。
4. 選ばれた点の連続性を維持し、欠測・省略された区間を線で結ばない。汎用縮約でも区間IDの数値再使用に対応し、間の区間が省略されても別区間を接続しない。
5. 描画点省略は `ProjectionTruncated`、取得保持上限による原データ喪失は `Truncated` と分離する。汎用縮約が描画点の省略を取得欠落として返す問題も修正した。

30秒の統計窓、標準偏差・平均・平均からの最大偏差、ステップ精度計算、入力取得頻度は維持する。開始直後や観測がない期間は実際の有効データの範囲で表示する。

## 検証と配布

macOS 14.6.1 ARM64、SDK 10.0.403 / runtime 10.0.14。全16プロジェクトのビルドは警告0/エラー0、依存lock16件は変更なし。**135件実行・135件合格**（Core60、HID21、XInput12、Application29、CLI13）。WPF19ケースはコンパイルのみ。Windows相当10MHzの時計と非ゼロの大きな起点で、1k/8k、45秒入力後の30秒範囲、極値、順序と区切りを検証した。future prefix、期限切れ、空窓からの再開も確認した。

検証中、既存のXInput低遅延テストが「観測カウンターが増えたが、キューへの公開前」という待機競合で1件失敗した。実フレームのキュー到着を待つよう試験を修正し、最終135件を再実行した。XInputの取得コードは変更していない。

4軸・解析10Hz、各60仮想秒の直列Release負荷で、通常の256段階波形と毎観測が別continuityとなる波形を確認した。全6条件で、原データの保持期間から描画投影で失われた時間は0秒。期間短縮による点数制限を使っていない。

これらはネイティブ入力・WPF・実時間スケジューリングを含まない仮想負荷。定常割当は40仮想秒以降の値であり、実秒のプロセス割当とは区別する。135件合格やこれらの数値をWindows描画受入済みとはしない。

GUI/CLIを単一EXEで再生成した。GUI 140,186,206byte、CLI 73,929,724byte。GUI389件/CLI182件の全バンドル入力、x64 host、共有GPSS DLL6件の一致を確認した。最終ZIPもCRCと全ファイルSHA256を照合して配布する。WindowsのWPF描画と実機入力は開発環境では実行できないため、原データから描画用Snapshotまでを合成入力で確認し、画面での再確認を残す。

Windowsでは新しいEXEで、30秒以上スティックを動かしてから、−30〜−20秒にも波形があることを確認する。状態番号飛びの表示、描画点省略の注記、統計の保持時間を併せて記録する。リセット・機器切替・無受信後の期限切れも確認する。単一EXE配布の設定とバンドル検査は[10](10-single-file-distribution.md)を継続する。旧配布物は `artifacts/GPSS-win-x64-before-history-fix.zip` に保全した。
